Panduan Hosting GitHub Pages

Satu file HTML mandiri, mendukung akses kamera HTTPS di GitHub Pages.

1. Unggah File

Simpan file ini sebagai index.html di repository GitHub bersama folder audio/ berisi file .mp3.

2. Aktifkan Pages

Buka Settings → Pages, pilih branch main / root lalu simpan. Domain HTTPS otomatis mengizinkan kamera.

3. Cara Kerja QR

Bisa memindai ID terdaftar (QR-AUDIO-01) maupun URL langsung (https://.../pos1.mp3).
